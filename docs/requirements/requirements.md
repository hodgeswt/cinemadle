# Requirements

## User Requirements

### User Characteristics

The expected Cinemadle user is a casual player who enjoys movies and guessing games.
They are likely to be familiar with popular movies and actors, and may have played
similar games in the past. They may have a familiarity with independent, lesser-known,
or older films, as these may be included in the game, but they are not expected to be
experts in these areas. The majority of the movies they must guess will be well-known.

The user is expected to have a basic understanding of how to use a web browser and
navigate a website.

### User Interfaces

The user will interact with Cinemadle through a web browser on mobile or desktop.

## System Requirements

### Functional Requirements

1. The system must present the user with a movie to guess.
1. The system must allow the user to make a guess.
1. The system must limit the number of guesses the user can make.
1. The system must provide the user with hints about the hidden movie.
1. The system must track the user's score.
1. The system must allow the user to restart the game.
1. The system must allow the user to view their score history.
1. The system must allow the user to view the instructions for the game.
1. The system must allow the user to share their score and achievements.
1. The system must show the user the correct answer if they run out of guesses.
1. The system must indicate to the user if they have guessed the movie correctly.
1. The system must select the same movie for all users at the same time.
1. The system must choose one movie per day, regardless of the number of users, and
   reset the game at midnight EST.
1. The system must provide the user with a way to contact the developers for support.

### Non-Functional Requirements

1. The system must be responsive and work on both mobile and desktop browsers.
1. The system must be fast and responsive, with minimal loading times.
1. The system must be secure and protect any relevant user data.
1. The system must be easy to use and intuitive, with clear instructions.
1. The system must be visually appealing and engaging for the user.
1. The system must be reliable and available 24/7, with minimal downtime.
1. The system must be scalable and able to handle a large number of users.
1. The system must be accessible to users with disabilities.
